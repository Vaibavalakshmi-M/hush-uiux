# 🌿 Hush – Mental Health Support App (UI/UX Design)

## 📌 Overview
**Hush** is a UI/UX design project focused on providing gentle and ethical mental health support for individuals experiencing mild to moderate depression. The app design prioritizes emotional safety, simplicity, accessibility, and user privacy.

Hush aims to create a calm digital space where users can reflect on their emotions, practice coping strategies, and access support resources when needed.

---

## 🎯 Problem Statement
Design a mobile application that helps individuals manage symptoms of depression through mood tracking, coping activities, journaling, and access to professional support resources in a safe and non-overwhelming manner.

---

## 💡 Design Goals
- Create a calm and supportive user experience
- Reduce emotional overload through minimal UI
- Encourage self-reflection without pressure
- Provide easy access to help resources
- Ensure accessibility for all users

---

## ✨ Core Features
- Daily mood check-in
- Guided coping activities (breathing exercises, grounding techniques, journaling prompts)
- Private and secure journaling space
- Gentle goal setting
- Crisis helpline and professional support resources
- Accessibility options for inclusive use

---

## 🔄 User Flow
Open App → Mood Check-in → Suggested Support → Activity or Journal → Gentle Encouragement

---

## 🎨 Design Approach
The interface uses:
- Soft color palettes for emotional comfort
- Minimal text to avoid cognitive overload
- Clear navigation for ease of use
- Supportive language for a non-judgmental experience
