# Hush – Mental Health Support App (UI/UX Design)

## Overview
Hush is a UI/UX design project focused on providing gentle and ethical mental health support for individuals dealing with mild to moderate depression.
The design emphasizes emotional safety, simplicity, and accessibility.

## Problem Statement
Design a mobile application that helps individuals manage symptoms of depression through mood check-ins, coping activities, journaling, and access to professional support.

## Core Features
- Daily mood check-in
- Coping activities (breathing, grounding, journaling)
- Private and secure journaling
- Gentle goal setting
- Crisis helpline and professional support
- Accessibility options

## User Flow
Open App → Mood Check-in → Suggested Support → Activity or Journal → Gentle Encouragement
